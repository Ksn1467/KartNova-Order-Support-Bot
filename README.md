# KartNova-Order-Support-Bot
AI-powered customer support bot for KartNova, developed using Google Gemini Gems. It uses Orders and Knowledge Base datasets to answer queries on orders, delivery, payments, returns, refunds, and store policies, with iterative testing to improve accuracy and reduce hallucinations.
